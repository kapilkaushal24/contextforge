# AI Token Optimizer — Chrome Extension

Manifest V3 extension shell. See
[docs/architecture/chrome-extension.md](../../docs/architecture/chrome-extension.md) for the
architecture this implements.

## Develop

```bash
npm install         # from repo root — installs all workspaces
npm run dev:extension
```

Then in Chrome: `chrome://extensions` → enable Developer mode → **Load unpacked** → select
`apps/chrome-extension/dist` (created by `vite build`, or kept live by `vite dev` + the CRXJS
HMR plugin).

## Build

```bash
npm run build:extension
```

Output goes to `apps/chrome-extension/dist` — a directly loadable unpacked extension.

## What's implemented (Phase 4 scaffold)

- MV3 manifest generated from `manifest.config.ts` (minimum-necessary permissions).
- Background service worker: message router (`OPTIMIZE_REQUEST`/`GET_SETTINGS_REQUEST`),
  stateless between invocations, calls the backend via `services/api-client.ts`.
- Content script: `IPlatformAdapter` factory wired up for ChatGPT, Claude, and a generic
  fallback; detects and re-detects the prompt input across SPA navigation.
- Popup and Options pages (React + Tailwind): mode selector, privacy-policy toggle, settings
  persisted to `chrome.storage.sync`.
- Placeholder icons generated by `scripts/generate-icons.py` — replace before shipping.

## Not yet implemented
