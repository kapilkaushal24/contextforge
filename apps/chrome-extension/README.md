# AI Token Optimizer — Chrome Extension

Manifest V3 extension shell. See
[docs/architecture/chrome-extension.md](../../docs/architecture/chrome-extension.md) for the
architecture this implements.

## Develop

```bash
npm install         # from repo root — installs all workspaces
npm run dev:extension
```

Then in Chrome: `chrome://extensions` → enable Developer mode → **Load unpacked** → select
`apps/chrome-extension/dist` (created by `vite build`, or kept live by `vite dev` + the CRXJS
HMR plugin).

## Build

```bash
npm run build:extension
```

Output goes to `apps/chrome-extension/dist` — a directly loadable unpacked extension.

## What's implemented

- MV3 manifest generated from `manifest.config.ts` (minimum-necessary permissions), platform
  origins derived from `constants/platforms.ts` (ADR-009).
- Background service worker: proxies `OPTIMIZE_REQUEST` to the backend, stateless between
  invocations; auto-detects the active tab's AI platform on every tab switch.
- Content script: `IPlatformAdapter` factory (ChatGPT, Claude, generic fallback) plus a
  proactive optimization widget (ADR-010) — watches the prompt, shows a local token estimate,
  and on **Optimize** calls the backend and renders before/after, confidence, review reasons,
  and Apply/Reject/Undo in an isolated shadow-DOM panel. See
  [docs/architecture/chrome-extension.md §3b](../../docs/architecture/chrome-extension.md).
- Popup and Options pages (React + Tailwind): mode selector, privacy-policy toggle, live
  platform-detection badge, settings persisted to `chrome.storage.sync`.
- Placeholder icons generated by `scripts/generate-icons.py` — replace before shipping.
- `npm test` (vitest) covers the widget's state machine, the token estimator, and the
  review-reason humanizer — all pure, DOM-free logic. The DOM-touching wiring is verified by
  building and loading the unpacked extension, not by unit tests.

## Not yet implemented / not yet verified

- **Live DOM verification.** The ChatGPT/Claude selectors and the widget's behavior on the real
  pages have not been checked against a logged-in browser session in this environment — load
  the unpacked extension and try it on both sites before shipping.
- Historical stats in the popup dashboard (today's-stats-only is MVP scope; see
  [docs/product/mvp-scope.md](../../docs/product/mvp-scope.md)).
